# طبقة الخدمات وجلب البيانات (Services Layer)

تم بناء طبقة الخدمات وفقاً للوثيقة الرسمية للفريق (`Frontend.pdf`)، حيث تدعم التبديل التلقائي الذكي بين:
1. **وضع المحاكاة (`USE_MOCK_API = true`):** يقرأ من مجلد `src/mocks/` مع محاكاة تأخير الشبكة وحالات الخطأ والفراغ.
2. **وضع الربط الفعلي (`USE_MOCK_API = false`):** يستدعي دوال `apiRequest` المركزية من `@/lib/api-client` مع المسارات الافتراضية المعرفة في `@/lib/api-config`.

### قائمة الخدمات الثمانية الأساسية:
1. `auth.service.ts`: إدارة تسجيل الدخول، إنشاء الحساب، استعادة كلمة المرور، واسترداد المستخدم الحالي.
2. `dashboard.service.ts`: جلب ملخص لوحة التحكم والمؤشرات الرئيسية.
3. `data-sources.service.ts`: إدارة مصادر البيانات، فحص الاتصال، والإضافة والتعديل والحذف.
4. `documents.service.ts`: إدارة المستندات وقاعدة المعرفة، رفع الملفات، وإعادة معالجة الفهارس.
5. `chat.service.ts`: محادثة الذكاء الاصطناعي ودالة `askQuestion` القياسية وجلسات الاستفسار.
6. `analytics.service.ts`: جلب مؤشرات الأداء والرسوم البيانية ومسار الاستعلامات.
7. `reports.service.ts`: إدارة واستعراض وتوليد وتنزيل التقارير وسجلات التصدير.
8. `profile.service.ts`: إدارة وتحديث الملف الشخصي وتفضيلات الواجهة والتنبيهات.
